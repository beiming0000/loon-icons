# Loon Icons

为 Loon 制作的 `144 × 144` 透明 PNG 图标，尺寸与留白参照
[Koolson/Qure Color](https://github.com/Koolson/Qure/tree/master/IconSet/Color)。

## 图标直链

- Bybit：`https://raw.githubusercontent.com/beiming0000/loon-icons/main/Bybit.png`
- Kraken：`https://raw.githubusercontent.com/beiming0000/loon-icons/main/Kraken.png`
- bunq：`https://raw.githubusercontent.com/beiming0000/loon-icons/main/bunq.png`

示例：

```ini
img-url = https://raw.githubusercontent.com/beiming0000/loon-icons/main/Bybit.png
```

这些品牌名称和标志的权利归各自所有者所有。本仓库仅用于个人配置中的图标显示。
